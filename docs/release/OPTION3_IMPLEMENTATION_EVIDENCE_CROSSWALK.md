# Option 3 Implementation and Evidence Crosswalk

**Status:** local source inventory only. The selected architecture is an external protected admission/controller, one-use isolated executors, an independent publisher, and verifiable receipts. This crosswalk distinguishes repository reference contracts from externally operated components and accepted evidence. A local implementation or synthetic test does not establish a deployed boundary, owner approval, trust, or release acceptance.

**Selected topology:** Linux/VDS for PAPER deployment, separate mandatory Darwin acceptance, and a distinct historical-backtester executor class. Exact hosts, images, provider identities, keys, trust roots, runner groups, and remote evidence systems remain unselected. See [External Execution Boundary V1](EXTERNAL_EXECUTION_BOUNDARY_V1.md), [PAPER Support Profile Decision](PAPER_SUPPORT_PROFILE_DECISION.md), and [External Execution Owner/Admin Decision Packet](EXTERNAL_EXECUTION_OWNER_ADMIN_DECISION_PACKET.md).

## Evidence limits and hold

The local tests listed here exercise repository contracts with synthetic fixtures. They do not inspect or attest to live GitHub/provider settings, owner/admin identities, runner configuration, keys, trust roots, host isolation, or remote storage. No external configuration value is inferred from a path, class, test name, or successful synthetic check.

This document does not open any gate or authorize Actions/CI, dispatch, workloads, SEARCH, HOLDOUT, PAPER, publication, deployment, merge, push, or release. No external inspection, tests, dispatch, CI run, workload, or remote write was performed to prepare this document; only local source and documentation paths were reviewed.
