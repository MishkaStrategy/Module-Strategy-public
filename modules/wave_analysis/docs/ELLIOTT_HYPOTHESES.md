# Elliott-like hypotheses

The layer is optional and disabled by default. It produces bounded ranked interpretations for common impulse, correction, extension, truncated fifth, diagonal-like, complex and incomplete structures.

Hard rules invalidate a candidate. Guidelines affect score only. An active scenario that breaches its invalidation price transitions to `invalidated`; the bounded history can preserve an invalidated alternative while the primary feature selects the best non-invalidated scenario.

These hypotheses are not facts, signals or entry models.
